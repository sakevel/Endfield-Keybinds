# 测试与验证指南

本文档介绍 Endfield-Keybinds（原生按键绑定库）的自动化测试套件与功能验证方法。

---

## 自动化测试

项目包含 Native C++ 接口测试与 Python / Lua 按键绑定逻辑测试：

```powershell
ctest --test-dir build -C Release --output-on-failure
```

### 测试套件说明

- **PluginTests (`tests/plugin_tests.cpp`)**：
  - 验证模组导出函数 `ZML_PluginV1` 与 `ZML_KeybindsV1` C ABI 结构一致性。
  - 验证配置项生命周期与内部资源初始化。

- **NativeTests (`tests/native_tests.cpp`)**：
  - 测试底层按键状态（按下/松开/边沿脉冲）的采样与线程安全性。
  - 验证在窗口失焦或文本输入状态下的按键拦截与抑制机制。

- **Behavior & Client Tests (`tests/client.py` / `tests/behavior.py`)**：
  - 模拟游戏原生设置面板，验证模组动作列表的动态注入。
  - 测试按键录入冲突检测、组合键解析以及修改放弃回滚逻辑。
  - 验证配置序列化格式（`bindings.ini`）的保存与恢复。

---

## 实机功能验证清单

在游戏内测试时，可按照以下流程验证：

1. **设置页面入口**：
   - 打开「设置」→「按键绑定」，滚动到底部，确认显示「模组 · <模组名称>」按键分组。

2. **按键录入与清除**：
   - 点击任意动作的主键槽位，按下自定义键位（或组合键如 `Ctrl+F`），确认键位正确填入槽位。
   - 鼠标悬停在已设置的按键上，点击清除按钮，确认按键重置为未绑定状态。

3. **保存与热生效**：
   - 点击右下角「保存设置」，返回游戏测试对应按键功能是否正常触发。
   - 再次进入设置，点击「恢复默认」，确认按键恢复为模组初始默认值。
